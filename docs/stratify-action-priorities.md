# SteelWyre Stratify: Action Priorities & Risk Mitigation
**Tactical Checklist Based on Platform Analysis**

**Date:** February 25, 2026
**Purpose:** Prioritized action items to address defensibility risks and maximize segment value

---

## CRITICAL (Do Within 30 Days)

### 1. Clarify & Reframe Task Metric

**Current Risk:** "50 AI tasks/month" is vague and causes confusion

**Actions:**
- [ ] Define what counts as 1 task (recommendation: 1 "campaign action" = 1 task)
  - Examples: 1 blog post generated, 1 email sequence created, 1 ad campaign deployed
- [ ] Update pricing page with clear examples
- [ ] Reframe pricing in sales materials as "campaigns" not "tasks"
  - Starter: "Create 1 strategy, publish 10 campaigns/month"
  - Growth: "Create 3 strategies, publish 30 campaigns/month"
  - Scale: "Unlimited strategies and campaigns"
- [ ] Train support team on metric explanation (common objection to address)
- [ ] Measure conversion impact (does clarity increase trial-to-paid conversion?)

**Expected Impact:** +10-15% trial-to-paid conversion (reduce confusion objection)

---

### 2. Analyze Starter Tier Unit Economics

**Current Risk:** $49/mo may not cover COGS; entire business model depends on upgrade rate

**Actions:**
- [ ] Calculate actual COGS per Starter user (hosting, APIs, inference, support)
- [ ] Project monthly margin per Starter user
- [ ] If margin <$5/mo, model impact of raising Starter to $69 or $79
- [ ] Analyze: What's the break-even upgrade rate? (if 40% need to upgrade within 6 months, what's current?)
- [ ] Set alert: If Starter→Growth upgrade rate drops below 40%, trigger pricing review
- [ ] Decision: Price or product change needed by Q3 2026

**Expected Impact:** Sustainable unit economics (or identify pricing issue early)

**Expected Impact:** 20-30% increase in trial-to-paid conversion (proof matters)

### 4. Fix Messaging: Channel Focus vs. Breadth

**Current Risk:** "46 channels" makes SteelWyre sound unfocused; competitors look specialized

**Actions:**
- [ ] Identify actual core channels by usage (what % of users use each?)
- [ ] Focus homepage/sales messaging on top 5-6 channels:
  - Recommendation: Meta, Google Ads, Email, SMS, Shopify, TikTok
  - Tagline: "Strategy to execution on the channels that matter"
- [ ] Update competitor comparison (vs. Jasper, Copy.ai, HubSpot) highlighting core channels
- [ ] Create channel playbooks: Show what agents actually do per channel
  - Meta: Dynamic audience selection, creative testing, bid optimization
  - Email: Segmentation, trigger-based sequences, lifecycle automation
  - Google Ads: Keyword selection, match type strategy, landing page optimization
- [ ] De-emphasize other 40 channels: "Plus integrations with 40+ platforms via Zapier"
- [ ] A/B test messaging: "46 channels" vs. "Master 5 core channels + scale to 40+"

**Expected Impact:** +15-20% conversion (focused messaging beats generic)

## Red Flags: When to Escalate

**If these happen, escalate immediately:**

1. **Starter→Growth upgrade rate drops below 30%** (business model risk)
2. **Churn spikes above 10%/month on any tier** (product problem)
3. **Any competitor (Jasper, Copy.ai) launches competing feature** (12-month timer starts)
4. **Case study ROI data is negative** (messaging/product misalignment)
5. **Segment-specific feedback consistently requests same feature** (prioritize that feature)
